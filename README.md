# Platformer Unity Prototype

This repository contains Unity C# scripts and an example level JSON for a simple 2D platformer prototype (double-jump, moving platforms, JSON level loader).

How to use:
1. Create or open a Unity 2D project.
2. Copy the `Assets` folder contents from this repository into your project's `Assets` folder, or clone this repo inside your Unity project.
3. Create prefabs for `platformPrefab`, `movingPlatformPrefab`, `coinPrefab` as described in the repository README or previous instructions.
4. Attach scripts to GameObjects and assign references in the Inspector (Player groundCheck, LevelLoader references, etc.).

If you want a pre-built `.unitypackage` with prefabs and simple sprites, reply and I will add it to the repo.
